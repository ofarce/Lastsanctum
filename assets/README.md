# assets/

- `baked/` : sorties du baker (`tools/baker/`). **Ne jamais modifier à la main** ; régénérer avec le baker.
- `imported/` : images reprises telles quelles du prototype (atlas du portail, etc.). `imported/engineer/engineer_bare_*` : Ingénieur sans armure (repos, marche, à genoux, incantation, tir, portrait), générés par `planches/ingenieur-sans-armure-export.html`. `imported/engineer/engineer_aim.*` : poses de tir de l'Ingénieur (lance-pitons), générées par la planche `planches/ingenieur-creusage-propositions.html` (EngineerKit, `makeSusp().poseFor`).
- `fonts/` : polices libres (décision D7).
