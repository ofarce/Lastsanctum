# Polices

`NotoSerif-Regular.ttf` et `NotoSerif-Italic.ttf` : Noto Serif (Google), sous licence SIL Open Font License 1.1 (texte complet dans `NOTO_COPYRIGHT.txt`, copié du paquet Debian fonts-noto-core).

Décision D7 (MIGRATION_PLAN.md) : le prototype affiche le HUD en Georgia, une police propriétaire. Noto Serif est une police libre à empattements, de proportions proches, qui couvre le français et les signes utilisés (★, ·, ’, ×, ▸).

`DejaVuSans.ttf` : police de secours pour les signes absents de Noto Serif (★ des niveaux, ▸), comme le repli du navigateur dans le prototype. Licence Bitstream Vera et domaine public (`DEJAVU_COPYRIGHT.txt`).
