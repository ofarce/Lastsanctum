# autoload/

Singletons globaux, enregistrés dans project.godot :

- `Events` (events.gd) : bus de signaux qui découple la simulation, le rendu et le HUD.
- `GameState` (game_state.gd) : état de la partie (temps de simulation, Ancre, ressources, vague, sélection, mode de placement).
- `Balance` (balance.gd) : accès typé aux constantes de jeu chargées depuis `res://data/`.
